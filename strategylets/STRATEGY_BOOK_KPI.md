# 策略书 KPI 与准入标准

## 目的

leader 提的核心问题不是“这个策略有没有想法”，而是“做到什么程度，才算够格写进策略书”。  
这份文档把它拆成一套统一口径，避免每次都凭感觉判断。

## 总原则

- 先过自动门槛，再做人工复核。
- 自动门槛解决“机会够不够、基线惨不惨、样本够不够、有没有未来函数”。
- 人工复核解决“图上看起来像不像真人会做的交易”。
- 任何一个硬前提不满足，都不进入策略书。

## 两段式流程

### 第一段：自动门槛

每个标准策略运行后，默认生成一份 `strategy-book-assessment.json`，并在 README 中显示同样的评审结果。

当前版本的自动 KPI 为：

1. `无过滤机会频率`
   - 定义：`signal_count / sample_days`
   - 口径：先用 `signal_count` 近似 `unfilter` 机会数
   - 通过线：`>= 1.00 次/天`
   - 观察线：`>= 0.40 次/天`
   - 低于观察线：暂不纳入

2. `基线表现`
   - 通过线：`avg_r >= 0` 且 `profit_factor >= 1.0` 且 `max_drawdown >= -0.25`
   - 观察线：`avg_r >= -0.05` 且 `profit_factor >= 0.95` 且 `max_drawdown >= -0.35`
   - 低于观察线：暂不纳入

3. `样本充足性`
   - 通过线：baseline 交易 `>= 120` 笔
   - 观察线：baseline 交易 `>= 60` 笔
   - 低于观察线：先继续研究，不直接入书

4. `实盘化前提`
   - 必须 `realtime_safe = true`
   - 必须 `uses_future_bars = false`
   - 必须 `supports_visualization = true`
   - 任一不满足：直接不纳入

自动门槛的结论分三档：

- `可进入人工复核`
- `观察名单`
- `暂不纳入`

### 第二段：人工图表复核

自动门槛通过后，不直接进策略书，还要做真人交易员复核。

建议固定抽样方式：

- `Top20`：按得分最高的样本抽 `20` 张
- `Random20`：按时间分散随机抽 `20` 张

建议复核问题：

1. 这是不是一个真人交易员能一眼解释的结构？
2. 触发点是否自然，而不是“规则拼出来但图上很别扭”？
3. 止损位置是否合理，而不是过远或过近？
4. 目标位是否有现实空间，而不是纸面上才成立？
5. 是否存在明显“像未来函数”或“明显误触发”的样本？

人工复核通过线建议先定为：

- `>= 70%` 的样本被判定为“结构合理、可解释、像真人会做”
- 明显误触发 / 明显未来函数嫌疑样本 `<= 3` 张

人工复核结论分三档：

- `通过`
- `待人工复核`
- `不通过`

## 最终准入结论

| 自动门槛 | 人工复核 | 最终结论 |
| --- | --- | --- |
| 可进入人工复核 | 通过 | 可纳入策略书 |
| 可进入人工复核 | 待人工复核 | 待人工复核 |
| 可进入人工复核 | 不通过 | 暂不纳入 |
| 观察名单 | 通过 | 观察名单 |
| 观察名单 | 待人工复核 | 继续观察 |
| 暂不纳入 | 任意 | 暂不纳入 |

## 为什么这样拆

- `机会频率` 解决“是不是太稀有，不值得先写入策略书”
- `基线表现` 解决“是不是连 break even 都做不到”
- `样本充足性` 解决“是不是只有少数样本碰巧好看”
- `实盘化前提` 解决“是不是根本没法实时用”
- `人工图表复核` 解决“是不是量化规则看起来成立，但真人根本不会这么做”

## 当前落地方式

仓库内的标准策略运行后，会在输出目录增加：

- `strategy-book-assessment.json`
- `README.md` 中的 `策略书 KPI 与准入` 小节

推荐使用方式：

1. 先跑策略，拿到自动 KPI。
2. 自动结论若为 `暂不纳入`，先修策略，不做人工复核。
3. 自动结论若为 `可进入人工复核` 或 `观察名单`，再做图表抽样复核。
4. 最终只把 `可纳入策略书` 或业务明确接受的 `观察名单` 写入策略书。
